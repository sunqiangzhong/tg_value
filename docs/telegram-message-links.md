# Telegram 单条消息链接下载

在已认证的机器人聊天中发送「链接 [文件夹名]」，链接放在前面：

```text
https://t.me/lspyanxi/4375
https://t.me/lspyanxi/4375 视频1
https://t.me/lspyanxi/4375 2026-09-09
```

机器人只下载该消息中的文件，不扫描整个频道或相邻消息。支持视频等现有文件类型，以及 Markdown 格式 `[视频](https://t.me/lspyanxi/4375)`。

下载沿用当前聊天 `/target` 设置的存储目标，以 `/p`（下一次）或 `/ps`（持续）设置的目录为根目录，在其下创建后缀指定的子文件夹；不填后缀则使用上海时区当天日期。未设置根目录时，在存储根目录下创建分类文件夹。一次性设置会被消费，持续设置会保留。链接预览不会被当成上传文件。

例如，已将宿主机目录挂载到 `/data/uploads/telegram`，选择本地存储并发送 `/ps telegram` 后：后缀 `视频1` 保存到 `telegram/视频1/`；后缀 `2026-09-09` 保存到 `telegram/2026-09-09/`；无后缀且上海日期为 2026-09-10 时保存到 `telegram/2026-09-10/`。日期后缀不是消息发布日期筛选条件。名称允许空格，但不能包含路径分隔符、相对路径或非法字符。

Telegram 指令菜单中的 `/tg_link` 和 `/help` 提供上述示例。也可发送 `/tg_link 消息链接 [文件夹名]`，效果与直接发送链接相同。`/tg_download` 保留原有按日期、标签批量下载功能。

`/ps` 已加入指令菜单：点击后输入根目录，或直接发送 `/ps telegram`。设置持久保存，重启或超过 7 天也不会失效，直到手动切换或 `/pc` 清除。此前保存的会话目录也会继续使用。

网页「设置 → 高级任务设置 → Telegram 下载进度刷新间隔」可选择 3、5、10、15、30 或 60 秒，默认 5 秒。进度自动编辑原消息，显示文件下载比例和分类目录，不重复发送提醒。运行中的任务会在后续刷新周期读取新设置。完成或失败等状态变化会即时更新。

消息链接优先于未结束的日期/标签向导处理，避免将文件夹名误当作标签。真正的批量日期/标签搜索匹配到 0 个文件时会明确提示没有下载，而不显示成功。单条链接任务也可在 `/tasks` 中查看和控制。

下载账号必须能够访问频道。私密消息链接 `https://t.me/c/频道编号/消息编号` 还需满足现有频道来源白名单规则；此功能不会自动加入频道。无文件、已删除或不可访问的消息会给出提示。可通过 `/tasks` 查看任务进度。

更新后需重新构建并部署应用镜像，单纯重启旧镜像不会启用此功能。
