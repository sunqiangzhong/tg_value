# Telegram 单条消息链接下载

在已认证的机器人聊天中直接发送一条消息链接：

```text
https://t.me/lspyanxi/4375
```

机器人只下载该消息中的文件，不扫描整个频道或相邻消息。支持视频等现有文件类型，以及 Markdown 格式 `[视频](https://t.me/lspyanxi/4375)`。

下载沿用当前聊天 `/target` 设置的存储目标和 `/p`（下一次）或 `/ps`（持续）设置的保存目录；未设置时使用默认存储和自动目录规则。一次性设置会被消费，持续设置会保留。链接预览不会被当成上传文件。

例如，已将宿主机目录挂载到 `/data/uploads/telegram`，并选择本地存储后，发送 `/ps telegram`，随后直接发送视频消息链接即可保存到该挂载目录。

下载账号必须能够访问频道。私密消息链接 `https://t.me/c/频道编号/消息编号` 还需满足现有频道来源白名单规则；此功能不会自动加入频道。无文件、已删除或不可访问的消息会给出提示。可通过 `/tasks` 查看任务进度。

更新后需重新构建并部署应用镜像，单纯重启旧镜像不会启用此功能。
